# 模块化制作与防止重绘退化

本文件的独立模块制作与最终图不重绘规则适用于主控制图初建及裁切排版调整。用户确认后的换装遵循 SKILL.md 阶段四例外：以确认整图一次性换装；每套独立从同一确认版开始，不逐视图生成、不重新裁切拼版、不串行沿用换装结果。生成后核对版式、人物身份和皮肤，不承诺像素锁定。

## 输入与资产

保留原始照片不覆盖，建立原图到角度、表情、全身视图的对应表。保存独立模块、排版坐标、色彩参数和输出版本。人物名字和身高使用当前用户输入，不硬编码 TC李老师或175厘米。

参考数量受限时，优先减少单次任务范围。可以用普通图像工具将同类原照并排放入参考拼版，只裁切和等比缩放，不用生成模型制造参考，不拉伸、不生成式放大。关键正面脸和当前表情仍优先作为独立参考输入。注意工具对分辨率与内部缩图的限制；拼版不是无损绕过限制。

## 独立制作

1. 脸部角度：每个角度独立输出无字人像，使用对应原照。原照角度已合适时，优先保留面部，仅处理白底和服装。无该角度原照时明确该视角需要推断。
2. 表情：每次只处理一个表情，使用该表情原照与清晰正面身份原照。八张均为头部端正、面朝镜头的正脸特写，双眼连线水平、构图与脸部尺度一致；禁止歪头、俯仰、转头、侧脸和45°角，禁止手部入镜及托腮、扶额、摸脸等手势。准确匹配嘴角、唇峰、上下唇厚度、牙齿排列、露齿程度、下颚张开、眉眼和视线，眼球运动不能带动头部偏转。原照符合正面姿态时优先保留原始脸部；不符合时以正面身份照约束方向，仅迁移参考表情，不能声称原始像素完整保留。不得把微笑、大笑、惊讶和眨眼混用。缺失表情允许推断，但不得说已严格复现参考。
3. 全身：正面、侧面、背面各自生成高分辨率独立图。每次同时使用对应全身原照和对应脸部原照，保留实际头身比例、肩宽、肩斜、胸腹厚度、四肢比例。先检查独立图中的脸，再缩入最终图纸。身高不能唯一确定头身比，不套用标准模特比例。三张图等比统一到相同高度和基线，禁止横向拉伸纠正肩宽。
4. 五官：从清晰原始脸部或已验收的人像中裁出眼眉、耳、鼻、闭嘴、露齿五格。优先使用真实原照，不额外生成皮肤纹理。原图不够清晰则降低展示尺寸或说明细节不足，不编造超清毛孔。

需要生成的内容仍用图像生成工具；裁切、缩放、蒙版合成、色彩调整和排版使用确定性图像工具。首次采用此流程时明确告知这一分工。若执行环境或用户明确要求所有图片操作仅由生成工具完成，遵循该要求，并说明无法保证未修改像素不变，不能假装完成确定性合成。

## 保护原始皮肤与统一颜色

使用一张光线均匀的原始脸部照作为色彩基准。皮肤准确度优先于夸张的“超清细节”。保留自然毛孔尺度、绒毛和少量原有瑕疵；不要反复给生成图追加“强化微距皮纹”。

轻微曝光、白平衡与曲线调整使用非生成方式，在模块上保存可回退参数。只对目标皮肤区域调整，保持自然明暗层次；不能用模糊磨皮处理杂色。用户要求牙齿更白时仅调整牙齿颜色，保留边缘、形状、排列和半透明感。已有涂抹、迷宫皮纹等生成伪影时，从原照重新制作受影响模块，禁止用全图重绘继续覆盖。

有可靠蒙版时可将原始面部保留在匹配姿态的模块中。不要把角度不匹配的脸硬贴到身体上；检查头颈连接、发际线、透视、边缘和光线。无法可靠匹配时重做该模块，不能承诺无缝或100%身份还原。

## 合成与验收

使用 SKILL.md 固定版式，通过坐标放置模块。名字由字体排版写入右下角，生成模块均不带文字。保留高分辨率模块供放大检查；最终图纸尽量只缩放一次，不能用放大低清图冒充新细节。

拼版前先统一裁切，不直接将比例不同的模块各自缩入格子而导致人头忽大忽小：

- 上方三角度采用完全相同的输出图幅宽高，按头顶至下巴的高度确定等比缩放尺度，对齐头顶留白与图幅底边，适当裁切上半身；不能通过横向或纵向拉伸来匹配人物比例。
- 下方八个表情采用领口向上的近景裁切，保留完整发顶、脸、颈部及少量领口，去掉多余胸腹和手臂。统一头部尺度、图幅与间距；张嘴造成的下巴变化应保留，不为机械对齐而变形。
- 保存每格的源文件、裁切坐标、等比缩放尺度和目标矩形。仅重新裁切拼版时，不调用生成模型、不添加锐化或磨皮；直接使用独立高分辨率模块，避免从已缩小的整图反复放大。
- 已确认图的局部排版修改仅替换指定格子，未改区域从上一版原样保留，并验证像素不变；旧版与模块不覆盖。

在原尺寸和最终展示尺寸分别检查全身脸、嘴形、肩宽与皮肤。只有通过查看对比才能说“更接近参考”，不要把提示词要求当成验收结果。未通过的模块最多针对性重试一次；仍失败如实指出。保留较好版本。

修改时重新制作该格，再合成。对同尺寸、同布局的局部替换，可以比较修改区域外像素确认其他格未变化。改排版则核验源模块未改变。最终合成图禁止再次送入生成模型统一画质、肤色或表情。
