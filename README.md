# yzzx-ip-control-sheet

一个用于 Codex 的真人角色控制图工作流 Skill。它通过分阶段收集真人参考照片，生成高写实人物控制图，并在用户确认身份还原后，为同一人物制作多套换装控制图。

## 适用场景

- 真人角色三视图与人物控制图
- 正面、侧面、45°脸部角度设定
- 多组标准化表情与五官细节
- 人物身份一致性修复
- 基于服装参考图的多套换装控制图

本 Skill 不适用于虚构人物的自由设计，也不用于普通单张人像美化。

## 工作流

Skill 严格按以下阶段推进：

1. 收集人物名字与身高。
2. 分轮收集全身照、脸部特写和表情特写，并检查照片可用性。
3. 分模块制作脸部角度、八种表情、五官微距和全身三视图；在图片外标注稳定编号，逐张或整批交由用户确认。仅重做问题图片并再次确认，全部待用图片确认后再以确定性方式排版，不提前制作审核拼版。
4. 展示主控制图，由用户确认或指定局部修复。
5. 主控制图确认后，根据服装参考图生成独立换装版本。
6. 整理并命名最终确认的控制图与换装文件。

主控制图未确认前不会进入换装阶段。局部修复只处理用户点名的格子或身体部位，先展示修改版并等用户确认，再与其他已确认模块拼合；代理验收不代替用户确认，未提及图片不自动确认。避免无关区域因整图重绘而发生漂移。

## 参考照片要求

为了获得更可靠的人物一致性，请准备：

- 清晰全身照：优先包含正面、正侧面、45°斜侧面和背面，头脚完整、无遮挡、不过度广角。
- 清晰脸部特写：优先包含正面、正侧面和45°角，光线均匀、无强滤镜。
- 清晰表情特写：建议覆盖微笑、大笑、惊讶、厌恶等需要精准复现的表情。
- 人物身高：用于结合照片判断自然头身比例，不作为拉长身体或改变体型的依据。

## 输出内容

主控制图采用横向白底摄影棚风格，包含：

- 三张脸部角度图：正面、侧面、45°角
- 五张五官微距：眼眉、单耳、鼻、闭合嘴唇、露齿嘴部
- 八张标准化正脸表情
- 全身正面、侧面、背面三视图
- 右下角人物名字；除此之外不添加其他文字

换装阶段会沿用已确认主控制图的人物身份、版式、比例和光线，只替换服装及用户明确选择的发型。每套服装都从同一张确认版独立生成，避免连续换装造成累计漂移。

## 安装

将仓库克隆到 Codex 的 Skills 目录：

```bash
git clone https://github.com/tychowu/yzzx-ip-control-sheet.git ~/.codex/skills/yzzx-ip-control-sheet
```

如果目标目录已经存在，可在该目录中拉取最新版本：

```bash
git -C ~/.codex/skills/yzzx-ip-control-sheet pull --ff-only
```

重新启动 Codex 或刷新 Skills 后即可使用。

## 使用

在 Codex 中明确调用 Skill：

```text
使用 $yzzx-ip-control-sheet 为我创建真人角色控制图。
```

Skill 会从询问人物名字开始，每次只索取当前阶段需要的资料。请按照提示逐轮上传照片，不需要一次提交全部内容。

## 设计原则

- 原始真人照片始终是人物身份的权威依据。
- 不承诺数学意义上的“100%相同”，也不擅自美化、瘦脸、改变肤色或体型。
- 主控制图采用独立模块生成与确定性拼版，最终拼版不再交给生成模型润色。
- 表情格统一为端正正脸，并使用固定顺序与一致构图。
- 全身三视图共同锁定肩宽、躯干厚度、四肢比例和自然头身比例。
- 皮肤保留符合尺度的毛孔、细纹和自然变化，避免塑料感、蜡像感与重复纹理。
- 明显缺陷最多针对性重试一次，避免无止境重绘导致其他区域退化。

## 隐私与限制

- 不会在未经授权的情况下公开人物照片，或把照片上传到无关服务。
- 参考图质量、图像工具能力和单次可接收的参考数量都会影响身份一致性。
- 当工具无法真正局部编辑或无法可靠锁定身份时，应明确说明限制，不把提示词要求当作已验证结果。
- 服装参考缺少背面、裤装或鞋履时，Skill 会依据可见风格合理补足，并明确这些部分属于推断。
